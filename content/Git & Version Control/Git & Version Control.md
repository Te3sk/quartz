### Suggested Structure
1. **Introduction to Git** (in this introduction file)
    - What Git is and why it’s used (version control, history, collaboration).
    - Key concepts: repository, commit, branch, merge.
2. **Basic Commands**
    - `git clone` → copy a repo locally.
    - `git pull` → update from remote.
    - `git add` → stage changes.
    - `git commit` → save changes locally.
    - `git push` → sync with remote.
3. **Working with GitHub**
    - How GitHub integrates with Git.
    - Repo structure and access.
    - Pull Requests explained (what they are, how to create/review).
4. **Team Workflows**
    - Branching strategies (main/dev/feature branches).
    - Merging and resolving conflicts.
    - Best practices for commit messages.
    - Collaboration tips (when to pull, how to sync before committing).
5. **Advanced & Useful Commands**
    - `git status`, `git log` → see history.
    - `git checkout`, `git switch` → move between branches.
    - `git stash` → save work temporarily.
    - `git revert` / `git reset` → undoing changes safely.
6. **Best Practices**
    - Commit often, in small chunks.
    - Always pull before pushing.
    - Communicate when merging.
    - Keep branches short-lived and focused.
